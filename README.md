# 坦克大战 Tank Battle

一个**纯单文件、零依赖**的 HTML5 Canvas 坦克大战小游戏。直接用浏览器打开 `index.html` 即可游玩，无需联网、无需安装任何东西。

## 玩法

守住底部基地（★ 老鹰），消灭每一关刷新出来的所有敌方坦克。清空本关敌人即可进入下一关，共 3 关，全部通关即胜利；基地被摧毁或命数耗尽则游戏结束。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 `↑ ↓ ← →` 或 `W A S D` |
| 开火 | `空格` 或 `J` |
| 暂停 | `P` |
| 开关音效 | `M` |
| 开始 / 重开 | `Enter` 或点击按钮 |

> 触屏设备会自动显示方向盘与开火按钮，可直接在手机上玩。

## 地形

- 🧱 **砖墙**：挡住坦克，子弹可逐格击碎。
- ⬜ **钢墙**：不可摧毁（吃到「星」道具后子弹可破）。
- 💧 **河流**：挡住坦克，子弹可穿过。
- 🌿 **草丛**：坦克可穿过，并遮挡坦克（伏击掩护）。
- ★ **基地**：底部中央，被击中即游戏结束。

## 道具

由特殊（闪烁）敌人被击毁后掉落，碰到即生效：

- ★ **星**：升级为双发子弹并提速。
- ⛨ **护盾**：一段时间无敌。
- 💣 **炸弹**：清场所有敌人。
- ♥ **加命**：多一条命。

## 本地运行

直接双击 `index.html`，或执行：

```bash
# 任选其一
python -m http.server 8000      # 然后访问 http://localhost:8000
# 或直接用浏览器打开 index.html
```

## 部署（GitHub Pages）

把本仓库推到 GitHub 后，在仓库 **Settings → Pages** 选择 `main` 分支根目录，即可获得一个在线试玩的静态页面。因为游戏是纯静态单文件，无需任何构建步骤。
